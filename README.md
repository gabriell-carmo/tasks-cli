# 📋 Tasks CLI

Gerenciador de tarefas via linha de comando feito em Python.

## 💻 Como rodar

```bash
python tarefas.py
```

## ⚙️ Funcionalidades

- ✅ Adicionar tarefas
- 📋 Listar tarefas
- 🎉 Concluir tarefas
- 🗑️ Remover tarefas

## 🛠️ Tecnologias

- Python 3
- Git & GitHub

## 📚 O que aprendi

- Funções em Python
- Listas e dicionários
- Loop while para menu interativo
- Versionamento com Git
